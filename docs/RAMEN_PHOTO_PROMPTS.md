# Ramen Photo Prompts

Paste each description below into any AI image tool (ChatGPT, Gemini, Canva, Midjourney all work),
then save the result as a JPG **with the matching file name** in `public/images/ramen/`.
The site automatically swaps the illustration for the photo; ramen without a photo keep the illustration.

Tip: landscape 4:3, about 1200px wide; end every prompt with the same closing description so the style stays consistent.
