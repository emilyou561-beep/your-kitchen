# 拉面照片生成清单

把下面的描述逐条粘贴到任何 AI 生图工具（ChatGPT、Gemini、Canva、Midjourney 都行），
生成后**用对应的文件名**保存为 JPG，放进 `public/images/ramen/`。
网站会自动用照片替换插画；没有照片的拉面继续显示插画。

建议：横版 4:3，宽 1200px 左右；每张都用同样的结尾描述，保证风格统一。
