# Yoru Kitchen

A Showa-retro Japanese home-cooking companion. Tell it what's in your fridge, discover authentic dishes, see what's missing, and get an editable grocery receipt.

Local MVP — no accounts, servers, or paid APIs. Data stays in your browser.

```bash
npm install
npm run dev
```

Open http://localhost:5173
